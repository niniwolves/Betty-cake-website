# 🍰 Betty — Homemade Cakes Website

A sweet and welcoming website concept for Betty's homemade cake business.

## 🌷 About the Project

Betty is a multilingual website concept designed to showcase homemade cakes and birthday cake offerings.

The website aims to provide a simple and friendly experience for visitors.

## ✨ Features

- Responsive website design
- Spanish, Japanese, and English language options
- Cake showcase section
- Birthday cake section
- About section
- Contact and ordering information section
- Warm and playful visual design

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- GitHub

## 🌎 Languages

- Spanish
- Japanese
- English

## 🚧 Project Status

The website is currently under development.

Product details, original cake photographs, business information, and ordering methods will be confirmed before launch.
